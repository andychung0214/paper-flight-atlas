# Paper Flight Atlas 設計規格

## 產品定位

- 專案名稱：Paper Flight Atlas
- 中文名稱：紙翼圖鑑
- 類型：紙飛機教學圖鑑／靜態網頁遊戲
- 平台：桌機瀏覽器優先，支援行動觸控
- 技術限制：HTML、CSS、Vanilla JavaScript；不使用 React、Angular、Vue、TypeScript、後端服務或大型遊戲引擎。
- 首版目標：可在靜態網站託管環境執行，並可部署至 GitHub Pages。

## 核心體驗

玩家像翻閱紙工坊手冊一樣，探索適合的紙材、四個難度與八種紙飛機機型，逐步閱讀摺法與 SVG 示意圖。首版採純教學圖鑑，不設計計分、計時或解鎖壓力，以翻閱、理解與收藏偏好作為主要體驗。

內容配置為四個難度，每個難度兩種機型：

1. 基礎：Classic Dart、Beginner Glider
2. 進階：Sky Arrow、Longtail
3. 困難：Swift Spear、Loop Wing
4. 大師：Origami Falcon、Wabi-Sabi Crane

每種機型包含名稱、簡介、難度、飛行特性、建議紙材、建議紙張尺寸、完成時間、步驟清單與教學提醒。每個步驟包含標題、詳細說明、常見錯誤、摺疊動作標籤與 SVG 示意圖識別碼。

## 資訊架構與路由

- `#home`：品牌介紹、今日推薦機型、難度入口、主題切換。
- `#catalog`：八種機型卡片，可依難度篩選與收藏。
- `#plane/:id`：單一機型的分步教學檢視器。
- `#about`：紙材與安全提示、內容說明、授權資訊。
- 未知雜湊網址回復至 `#home`，不顯示空白頁。

教學頁一次聚焦一個步驟，提供步驟進度、上一則／下一則、SVG 示意圖放大、收藏切換與回到圖鑑。手機使用底部步驟導覽，平板與桌機使用較寬的紙張工作台與側邊導覽。

## 程式架構

採用原生 ES Modules，讓內容資料、畫面產生、路由與儲存邏輯彼此分離：

- `index.html`：語意化入口、Meta、Open Graph、Product 結構化資料、Sitemap 與 robots 連結。
- `styles.css`：侘寂紙張風格、主題色、RWD、無障礙焦點與減少動畫支援。
- `src/main.js`：啟動程式、事件繫結與路由更新。
- `src/data/planes.js`：八種機型與全部教學內容。
- `src/router.js`：解析與產生雜湊網址。
- `src/render.js`：建立首頁、圖鑑、教學與關於頁。
- `src/diagrams.js`：依步驟示意圖識別碼產生內建 SVG 線稿。
- `src/storage.js`：主題色與收藏偏好讀寫。
- `tests/`：使用 Node.js 內建測試功能驗證純函式與資料完整性。

主要資料流：

```text
網址雜湊
  → router.js 判斷頁面
  → main.js 取得頁面資料
  → render.js 建立內容
  → diagrams.js 產生 SVG
  → 使用者操作
  → storage.js 儲存主題與收藏偏好
```

## 視覺方向

採用「日式侘寂紙工坊」作為主視覺，並混入少量復古飛行技術手冊的標註語彙。

色票：

- 紙張底色：`#F4EFE5`
- 墨色文字：`#292824`
- 森林綠：`#315047`
- 酒紅色：`#7A4148`
- 倫敦藍：`#49647B`
- 砂岩棕：`#B58B68`
- 紙張線條：`#D9D0C2`

其他候選風格曾評估為「復古飛行技術手冊」與「晴空紙飛行社」；首版不採用，避免弱化紙工坊的沉靜與教學感。

視覺規則：

- 使用米白紙張、細墨線、低飽和色彩與不完全對稱版面。
- 以 CSS 漸層製作非常淡的紙張纖維，不依賴外部圖片。
- 機型卡片像紙樣標本，保留編號、難度、飛行特性與建議紙材。
- 教學步驟使用「紙張面板＋SVG 線稿＋短標題＋詳細說明」。
- 字體使用具日系質感的系統無襯線字型：`"Noto Sans TC"`, `"Yu Gothic"`, `"Hiragino Kaku Gothic ProN"`, `sans-serif`。
- 動畫只表現翻頁、紙張滑入與摺線描繪，速度約 180–280ms；啟用減少動畫時停用。
- 禁止霓虹高彩度、玻璃擬態、過度圓角、滿版漸層、漂浮陰影堆疊、無意義裝飾圖示與大量 AI 風格插畫。

三組 RWD 斷點：手機單欄、平板雙欄、桌機寬版工作台。

## 狀態與錯誤處理

- 主題儲存鍵：`paper-flight-atlas.theme`。
- 收藏儲存鍵：`paper-flight-atlas.favorites`。
- localStorage 讀取失敗時使用記憶體預設值，畫面仍可操作。
- 無效機型識別碼回到圖鑑並顯示可理解的提示。
- SVG 識別碼不存在時使用安全的預設摺線圖，不插入未驗證的 HTML。
- 所有使用者可見內容採用 DOM API 或安全文字插入，避免直接把外部輸入當成 HTML。

## 無障礙與相容性

- 使用語意化標題、導覽、主區塊、按鈕與列表。
- 主題切換、收藏、上一則／下一則均可用鍵盤操作。
- 步驟狀態使用 `aria-live="polite"`，SVG 提供可理解的替代文字。
- 焦點樣式清楚且不依賴顏色單獨傳達狀態。
- 按鈕符合行動觸控尺寸，支援窄螢幕與橫向空間不足。
- `prefers-reduced-motion: reduce` 停用非必要動畫。

## 測試與驗收

使用 Node.js 內建 `node:test` 與 `node:assert/strict`，以 `npm test` 執行：

- 八種機型資料存在，四個難度各兩種。
- 每個機型都有紙材、特性、步驟文字與 SVG 示意圖。
- 路由解析與未知路由回復。
- 主題與收藏狀態的讀寫與無 localStorage 環境回復。
- SVG 產生器輸出安全且具有必要標籤。

里程碑完成時執行自動測試或以瀏覽器實際檢視靜態頁面，並保存命令輸出作為證據。交付前再執行完整測試、靜態伺服器檢查與 Git 工作樹檢查。

## 部署與 Git

- GitHub Pages 直接服務專案根目錄，不需要建構步驟。
- Git 分支使用 `feature/paper-flight-atlas`。
- Commit 描述使用繁體中文 Conventional Commits，例如 `docs: 建立紙翼圖鑑設計規格`。
- 推送前必須列出 remote、branch 與即將推送的 commit；不讀取或提交任何憑證、token、`.env` 或私人金鑰。
- 若沒有既有 remote，完成本地提交後回報需要的 remote URL，不自行猜測帳號或儲存庫位置。

## 非目標

- 不做帳號、後端 API、資料庫、金流或雲端同步。
- 不做即時飛行物理、排行榜、多人功能或複雜關卡。
- 不依賴外部圖片、外部字型服務或大型前端函式庫。
