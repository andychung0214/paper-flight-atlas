# 紙翼圖鑑產品與交付計畫

## 需求

紙翼圖鑑是一個靜態網站型紙飛機教學圖鑑。使用者可以從基礎到大師瀏覽八種機型，查看紙材、飛行特性、詳細文字步驟與 SVG 示意圖，並在瀏覽器中收藏機型與切換主題。

## 範圍

### 首版包含

- HTML5、CSS3、Vanilla JavaScript、SVG、原生 `dialog` 與瀏覽器儲存。
- 首頁、機型圖鑑、難度篩選、關於頁與逐步教學。
- 八種機型、四個難度，每種機型至少五個步驟。
- 雜湊網址、收藏、主題切換、Skip Link、live region、焦點恢復與行動觸控。
- 可直接開啟的瀏覽器原生測試頁。
- GitHub Pages 所需的 `sitemap.xml`、`robots.txt`、MIT 授權與文件。

### 首版不包含

- 帳號、雲端同步、伺服器 API、資料庫、多人遊戲或排行榜。
- 真實空氣動力計算、投擲軌跡模擬與自動辨識折紙影像。
- 外部圖片服務、付費內容或追蹤工具。

## 工作分解

1. 定義產品命名、Persona、核心流程與視覺風格。
2. 建立機型資料與難度分類，為每個步驟提供文字與示意圖 id。
3. 建立受控 SVG 圖示產生器，處理未知 id 與文字轉義。
4. 建立雜湊路由與畫面產生器，維持 metadata、live region 與焦點狀態。
5. 建立收藏、主題與儲存失效備援。
6. 以傳統 `<script>` 依序載入應用程式，將公開 API 放在 `window.PaperFlightAtlas`。
7. 建立 `tests/browser-test.html` 與原生測試，直接檢查實際入口頁契約。
8. 完成手動測試、文件、GitHub Pages 說明與授權。

## 風險與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| 本機檔案的跨文件檢視限制 | 測試頁可能無法直接讀入口頁 DOM | 使用入口頁 test-only `postMessage` 契約橋接，不使用 fetch 或伺服器 |
| 瀏覽器儲存被停用 | 收藏與主題無法持久化 | `storage.js` 捕捉讀寫例外，保留記憶體狀態 |
| 小螢幕操作區不足 | 行動使用者誤觸或難以閱讀 | RWD 斷點、足夠觸控尺寸、行動手動檢查 |
| SVG 文字被插入標記 | 產生不安全畫面 | 集中轉義 attribute/text，測試 `<script>`、原型鍵與特殊字元 |
| 雜湊網址格式錯誤 | 使用者進入空白頁 | 未知路由回到首頁並顯示可見備援狀態 |

## 驗收條件

- 直接開啟 `index.html` 可看到首頁，並能前往圖鑑、關於與八個教學頁。
- 圖鑑可依四個難度篩選，收藏與主題可切換；儲存不可用時仍可操作。
- 八種機型各有至少五個步驟，總步驟數為 40，SVG 示意圖均可產生。
- `tests/browser-test.html` 直接開啟後顯示全部測試通過。
- 測試涵蓋桌機、行動觸控、鍵盤焦點、Skip Link、dialog、減少動畫與安全轉義。
- README、視覺規格、測試計畫、貢獻指南、授權、網站地圖與 robots 檔案完整。
- Git 工作樹乾淨、commit 符合 Conventional Commits，且推送前已確認 remote、branch 與 commit。
