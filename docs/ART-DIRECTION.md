# 紙翼圖鑑視覺規範

## 色票

### 基底色

| 名稱 | 色碼 | 用途 |
| --- | --- | --- |
| 紙張底色 | `#F4EFE6` | 頁面背景與整體紙張氛圍 |
| 紙面高光 | `#FCF8F0` | 卡片高光與紙張層次 |
| 墨色文字 | `#1F1A16` | 主標題、主要按鈕文字 |
| 靜謐灰褐 | `#6F655C` | 內文、輔助說明 |
| 紙張線條 | `rgba(66, 56, 47, 0.16)` | 邊框、虛線、弱分隔 |

### 主題色

| 主題 | 主色 | 深色 | 建議使用情境 |
| --- | --- | --- | --- |
| 森林綠 | `#3D5A4D` | `#294337` | 預設主題、首頁、自然與平衡感 |
| 酒紅色 | `#6A3944` | `#4E232D` | 收藏狀態、較沉穩的教學閱讀情境 |
| 倫敦藍 | `#36566F` | `#213F56` | 導覽、焦點狀態、清晰資訊感 |

## 字體策略

- 優先使用系統可取得的日系質感無襯線字型。
- 建議字體串：
  - 主要文字：`"Hiragino Sans", "Yu Gothic", "Yu Gothic UI", "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif`
  - 標註字：`"Avenir Next", "Yu Gothic", "Noto Sans TC", sans-serif`
- 主標題使用較大的字級與較寬字距，保留紙樣標本卡的陳列感。
- 內文維持舒適行高，避免大量窄字距造成閱讀壓迫。

## 元件規格

### 紙張面板（`.paper-panel`）

- 使用柔和漸層與淡紙纖維紋理製造紙感。
- 邊框不可過粗，陰影需輕量且貼近紙面。
- 可在桌機寬版略帶微角度旋轉，營造手工擺放感。

### 導覽與按鈕（`.button`, `.button--ghost`）

- 主要按鈕使用當前主題色，膠囊形狀保持乾淨。
- 次要按鈕使用半透明紙白底與細邊框，不搶走主內容。
- 焦點樣式必須清楚，採實線外框而非只有陰影。

### 機型卡片（`.plane-card`）

- 每張卡片需同時顯示難度、摘要、飛行特性、建議紙材與操作按鈕。
- 卡片內部使用「標註字 + 內文」的節奏，像整理標本卡的欄位。
- 收藏按鈕與「查看教學」按鈕要靠近，減少跳轉成本。

### 教學面板（`.guide-layout`, `.diagram-frame`）

- 左側聚焦當前步驟與 SVG 示意圖，右側整理標題、提醒與常見失手。
- 示意圖容器使用虛線或淡框，像工作台上的定位區。
- 上一則／下一則按鈕應在窄螢幕下保持容易點按。

### 折法圖解語意 token

每張專屬折前／折後 SVG 均以相同語意 token 表達動作；圖例固定說明下列四個符號，且文字提示必須保留，避免只靠顏色傳達意義。

| 圖例項目 | 對應 token | 視覺語意與規格 |
| --- | --- | --- |
| 新折線 | `.diagram-crease` | 壓平前的折線位置；輔助墨色 `2px` 虛線，節奏為 `8 7` |
| 方向箭頭 | `.diagram-direction`, `.diagram-process` | 紙面移動方向；主題色 `5px` 實線與實心箭頭 |
| 移動紙面 | `.diagram-moving` | 本步要移動的紙層；半透明暖黃、主題色 `2px` 外框 |
| 對齊點 | `.diagram-alignment` | 需要重合的位置；主題色圓點及米白 `2px` 描邊 |

折前與折後的紙張輪廓分別使用 `.diagram-before`、`.diagram-after`，均採米白紙面、墨色 `3px` 實線。既有折痕使用 `.diagram-existing-crease` 淡線，當步完成折痕使用 `.diagram-result-crease` 輔助墨色 `2px` 實線；兩者不列入操作圖例。主圖與 dialog 的箭頭 marker 必須使用不同 id。

- 主圖在一般畫面以容器全寬縮放，不得超出圖解框。
- SVG 下方固定顯示 `.diagram-caption`，以至少 `16px` HTML 文字重述「左圖：折前 → 右圖：折後」與對齊提示，避免行動版縮放後只剩過小的 SVG 文字。
- 圖例在 560px 以下為單欄，560px 起為雙欄；放大 dialog 不重複顯示圖例。
- 420px 以下的放大圖保留水平捲動，讓完整 SVG 保持可讀；390 × 844 行動裝置的主畫面不得水平溢位。

## 動畫原則

- 動畫只用於紙張滑入、按鈕輕微浮動與紙卡層次轉換。
- 動畫時間維持在 180ms 至 280ms。
- 動畫不可干擾步驟閱讀與點按判斷。
- 偵測到 `prefers-reduced-motion: reduce` 時，停用所有非必要動畫與平滑捲動。

## 三個主題色的使用規則

- 森林綠為預設主題，適用於首頁、主要 CTA 與整體品牌識別。
- 酒紅色只在使用者主動切換後套用到全站，不單獨用作錯誤或警告色，避免語意混亂。
- 倫敦藍可作為焦點框與主題替代色，保持資訊檢視時的清晰感。
- 任一主題都必須維持足夠對比，不可讓按鈕或標註字難以辨識。

## 禁止事項

- 禁止使用霓虹高彩度、玻璃擬態、過度發光陰影。
- 禁止加入與紙飛機教學無關的裝飾插畫或大量圖示。
- 禁止把卡片圓角做得過度可愛化，破壞侘寂手作感。
- 禁止使用會誤導內容層級的強烈滿版漸層。
- 禁止使用外部追蹤腳本、外部圖片 CDN 或需要授權金鑰的視覺素材。
- 禁止以顏色作為折法唯一提示；方向、對齊與壓平資訊必須同時由箭頭、圓點、摺線與文字表達。
- 禁止在圖解中使用霓虹箭頭、發光、立體陰影、玻璃擬態或未標示意義的裝飾效果。
