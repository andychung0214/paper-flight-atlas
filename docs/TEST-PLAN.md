# 紙翼圖鑑測試計畫

## 測試原則

- 使用現代桌機或行動瀏覽器直接開啟 HTML。
- 自動測試入口為 `tests/browser-test.html`，不需要額外執行環境、套件或本機伺服器。
- 每次修改後先看瀏覽器測試摘要，再做對應的手動檢查。
- 不把靜態檢查結果誤稱為真實視窗操作；視窗、觸控與鍵盤情境要實際操作或明確記錄未完成項目。

## 功能測試清單

- [ ] 直接開啟 `tests/browser-test.html`。
- [ ] 顯示全部測試通過，沒有紅色失敗項目。

- [ ] `PaperFlightAtlas` namespace 與所有公開 API 存在。
- [ ] 八種機型、四個難度、40 個步驟資料完整。
- [ ] 路由、未知路由、收藏、主題與儲存失效備援通過。
- [ ] 全部步驟 SVG、安全轉義、未知示意圖與原型鍵通過。
- [ ] 直接雙擊測試頁、不加特殊瀏覽器旗標，確認全部測試通過。
- [ ] 瀏覽器自動檢查 40 個唯一圖解鍵值、相鄰步驟實際 path 連續性、折線端點對來源／目標等距、實際對齊目標、唯一 marker、圖例與響應式邊界均通過。
- [ ] 首頁、圖鑑、教學、關於、MIT 連結與繁體中文文案通過。
- [ ] 掛載、導覽、篩選、Skip Link、焦點、dialog 與取消操作通過。

### 手動功能測試

- [ ] 直接開啟 `index.html`，首頁能顯示推薦機型與導覽。
- [ ] 開啟圖鑑，確認八張機型卡與四個難度按鈕。
- [ ] 逐一切換基礎、進階、困難、大師，確認每組各有兩張卡。
- [ ] 開啟八個教學頁，確認五個步驟、上一則／下一則與示意圖。
- [ ] 逐步巡覽八種機型的 40 張專屬圖解，確認每張圖的移動紙面、摺線、方向箭頭與對齊點皆與文字步驟相符。
- [ ] 對每種機型逐步比對：第 2 至 5 步的折前輪廓必須與前一步折後輪廓相同；中心對摺後須明示展開。
- [ ] 確認主畫面每次只顯示一份四符號圖例，且放大 dialog 不重複圖例。
- [ ] 開啟放大示意圖，使用關閉按鈕與 Escape 取消，確認焦點回到開啟按鈕。
- [ ] 收藏與取消收藏，重新整理後確認瀏覽器仍保留狀態。
- [ ] 切換森林綠、酒紅色、倫敦藍，重新整理後確認主題仍保留。
- [ ] 開啟未知雜湊網址，確認回到首頁或圖鑑並有可見提示。

## 行動裝置測試

- [ ] 390px 寬度：首頁、圖鑑、卡片與教學文字不水平溢出。
- [ ] 以 390 × 844 檢查教學頁與放大 dialog：主圖不超出圖解框，窄幅 dialog 可水平捲動完整 SVG，關閉與 Escape 仍可操作。
- [ ] 390px 寬度的 HTML 圖解說明維持至少 16px，清楚顯示折前、折後與對齊提示。
- [ ] 768px 寬度：平板版欄位、導覽與篩選保持可讀。
- [ ] 1440px 寬度：桌機版卡片網格與紙張背景層次正常。
- [ ] 觸控按鈕有足夠間距，收藏、篩選、步驟與 dialog 不會誤觸。
- [ ] 旋轉裝置後重新檢查內容寬度與焦點位置。
- [ ] 行動瀏覽器重新整理後，主題、收藏與網址路由仍可恢復。

## 無障礙測試

- [ ] 使用 Tab 從 Skip Link、導覽、主題、主要操作一路移動，焦點順序合理。
- [ ] 啟用 Skip Link 後，焦點會落在主要內容區。
- [ ] 以鍵盤可完成導覽、篩選、收藏、主題、步驟與 dialog 關閉。
- [ ] 以螢幕閱讀器或瀏覽器輔助檢視確認頁面有 lang、標題層級、按鈕名稱與 aria 狀態。
- [ ] 教學步驟狀態使用 live region 告知目前步驟。
- [ ] SVG 有 role、aria-label、title，放大按鈕有 dialog 關係。
- [ ] 在灰階或關閉顏色辨識的情境下，仍可由圖例文字、箭頭、圓點與虛線分辨移動方向、對齊位置與摺線。
- [ ] 在偏好設定開啟「減少動態效果」時，動畫降低且內容仍可理解。
- [ ] 文字與背景有清楚對比，焦點外框不被紙張紋理淹沒。

## 安全與回歸測試

- [ ] 將特殊字元放入示意圖標籤與畫面資料，確認不產生 HTML 標記。
- [ ] 使用未知示意圖 id 與 `__proto__`，確認回到安全預設圖。
- [ ] 讓儲存讀取、寫入與刪除函式丟出例外，確認畫面仍可操作。
- [ ] 重新整理首頁、圖鑑與教學頁，確認不重複註冊互動事件。
- [ ] 確認來源只有 HTML、CSS、JavaScript、SVG 與靜態 XML/文字檔，沒有隱藏的套件或秘密檔案。
