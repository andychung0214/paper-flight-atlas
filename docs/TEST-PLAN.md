# 紙翼圖鑑測試計畫

## 測試範圍

- 自動測試：資料、路由、快取、SVG、畫面產生、入口檔案與交付文件。
- 手動測試：首頁、圖鑑、篩選、收藏、主題、教學切換、未知路由回復。
- 行動裝置測試：390px 手機、768px 平板、觸控點按與重新載入狀態。
- 無障礙測試：鍵盤導覽、焦點、Skip Link、`aria-live`、減少動畫偏好。
